This template provides a box on the side of a page that lists all shortcuts that link to that template (using [[Help:redirects|redirects]]). It should not be used on article pages (main space).

Taken from [[Wikipedia:Template:Template shortcut]]

==Syntax==
{{T|template shortcut|template name 1|template name 2|...}}
Where each template is the template name without "Template:"; only the first is needed

==Example==
<pre>{{Template shortcut|Clear}}</pre>
; Produces
{{Template shortcut|Clear}}
{{Clear}}

<pre>{{Template shortcut|Bc|Blank cell}}</pre>
; Produces
{{Template shortcut|Bc|Blank cell}}
{{Clear}}
