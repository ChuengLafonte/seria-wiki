{{Documentation subpage}}
{{Lua|Minion}}
Displays a [[minion]] stat table for use on a minion page.
{{Clear}}
==Syntax==
{{t|Minion stats table|minion}}
*'''minion''' = minion name without "Minion". ex: "Wheat"
==Example==
<pre>
{{Minion stats table|Wheat}}
</pre>
;Produces
{{Minion stats table|Wheat}}
