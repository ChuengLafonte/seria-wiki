{{Lua|Tag}}
Dark version of <code><nowiki><syntaxhighlight></nowiki></code>.

==Syntax==
{{t|DarkCodeBox|lang|text|bypass}}
*{{s|lang}} or {{s|l}} - any lang accepted by <code><nowiki><syntaxhighlight></nowiki></code>.
*{{S|text}} or {{S|t}} - the text to be formatted
*{{s|bypass}} or {{s|b}} - Displays the "Bypass" cache notice before the code box. This is mostly used on code pages where the page does not come with native syntax highlighting.
