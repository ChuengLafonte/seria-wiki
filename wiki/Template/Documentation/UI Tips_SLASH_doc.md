{{T|UI Tips}} is a template that should be used on all the '''UI pages''' (NOT on pages that include UIs) that involve clickable slots that goes to another article or changes the UI.
{{Tc}}

== Syntax ==
{{T|UI Tips|back}}
* {{S|back}} - links that goes to UI subpages that the reader might have accessed before going to that page. For example, a reader might have accessed [[SkyBlock Menu/UI]] before going to [[Collections/UI]].

== Examples ==
<pre>
{{UI Tips}}
</pre>
; Produces
{{UI Tips}}

<pre>
{{UI Tips|back=[[SkyBlock Menu/UI]]}}
</pre>
; Produces
{{UI Tips|back=[[SkyBlock Menu/UI]]}}
{{doc/end}}
