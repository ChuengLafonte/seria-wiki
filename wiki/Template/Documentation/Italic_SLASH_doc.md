A template that italicizes text. This template should typically '''not''' be used, as using the normal syntax for italicizing content (<code><nowiki>''Italic''</nowiki></code>) is both shorter, consistent across all wikis, more efficient than a template call, less confusing when used inside another template, and the normal syntax also has it's own syntax highlighting.
