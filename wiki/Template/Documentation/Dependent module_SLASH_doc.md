'''Dependent modules''' is a template used to show what modules depend on a particular module. This template works in exactly the same way as {{T|Template shortcut}}, so for more information go to that page.

== Example ==
<pre>{{Dependent module|Pet}}</pre>
; Produces
{{Dependent module|Pet}}
{{Clear}}
