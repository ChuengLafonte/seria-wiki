{{Lua|UI}}

{{T|UI Pager}} is a template used to generate a UI Pager, where items are added sequentially into pages of UI and navigation are added if there exists multiple pages. It uses the fill=border by default and sequentially allocates items inside the border.

{{T|Shop UI}} is a similar template but defaults to replaces the close button with a selling hopper on the bottom row.

{{T|Skill UI}} is a template where items are added sequentially into pages of UI in a snake formation, useful for skill experience UIs. It uses fill=true by default.

{{T|Rewards UI}} is similar to Skill UI, with a different formation to suit Rewards UIs.
{{Tc}}

== Syntax ==
{{T|UI Pager}}, {{T|Shop UI}}, {{T|Skill UI}}, and {{T|Rewards UI}} uses these common parameters.
{{T|UI Pager
|title
|...
|title_index{{=}}title_index
|index_last{{=}}index_last
|clickable{{=}}clickable
}}
* All parameters and syntax available to {{T|UI}} can also be used here.
* Any UI slots specified (for example: {{code|{{!}}1, 5{{=}}Diamond}}) will be written/overridden to every page generated by this template. Using rowN/colN syntax or writing to non-border slots will result in undefined behaviour, so it is not recommended.
* {{S|title}} - The UI title. This can be any form of text. In the title, if used, {{Code|{{(}}0{{)}}}} will be replaced with the max. pages, and {{Code|{{(}}1{{)}}}} will be replaced by the total pages.
* {{S|...}} - All the UI item slots, each using a syntax same as {{T|UI}}.
* The items will be allocated to the slots within the border from top-left to bottom-right. When a UI is full, it automatically writes into a new UI.
* Extra back/forth arrows will be added to each page if there are multiple.
* {{S|title_index}} - A shorthand to add {{Code|({{(}}0{{)}}/{{(}}1{{)}}) }} before title. Default false.
* {{S|index_last}} - If true and if {{S|title_index}} is true, put the index at the end of the UI title. Default false.
* {{S|clickable}} - A shorthand to enclose the whole thing inside a {{Code|1=<nowiki><div class="sbw-ui-tabber"></nowiki>}}. Default false.
* The default arrow on all pages will return to {{Code|return_id}} if specified.
* If {{Code|id}} is specified, each page is named: {{Code|<your id>}}, {{Code|<your id>-2}}, {{Code|<your id>-3}}, ...
* If {{Code|hide}} is specified, it will only be applied to the first page. Default false.
* All pages except the first will be hidden. This cannot be changed.

{{T|Shop UI}} has these additional parameters:
* {{Param|confirmation}} - This puts a shop confirmation slot next to the closing button: {{Slot|Lime Dye|link=none|title=&aShop Confirmations|text=&7Confirm when purchasing items/&7worth at least a million coins.//&eClick to disable!}}
