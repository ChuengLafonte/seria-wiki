{{Documentation subpage}}
Only inserts content onto the [[Help:Namespace|main namespace]]. As such, its primary use is within templates, for any information you'd only want displayed on article pages (such as categories).

See {{t|Namespace}} for a template with more options.

==Syntax==
<pre>{{Mainonly|content}}</pre>

==Example==
<pre>{{Mainonly|Categories rock! [[Category:Browse]]}}</pre>
is entered in below, but not displayed as this page is on the Template namespace (Note that as this is on a documentation page, it will never actually '''be''' on the main namespace).
{{Mainonly|Categories rock! [[Category:Browse]]}}

<includeonly>[[Category:General wiki templates]]</includeonly>
