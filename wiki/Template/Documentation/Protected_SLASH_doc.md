{{T|Protected}} is a template used to notify users that a page is protected.

== Syntax ==
{{T|Protected|1|type}}
* {{s|1}} (optional) - A reason given for page protection in written text.
* {{s|type}} or {{s|t}} (optional) - Reason for page protection. The list of valid values includes {{Code|high traffic page}}, {{Code|template}}, {{Code|dispute}}, and {{Code|excessive spam/vandalism}}.

{{Protected}}
</pre>

{{Protected}}

<pre>
