{{T|Parameter}} is a template used to format HTML/XML tags and hierarchy.

== Syntax ==
* <code><nowiki>{{Parameter|tag1|tag2|tag3}}</nowiki></code>

== Examples ==
* <code><nowiki>{{Parameter|div}}</nowiki></code> generates: {{Parameter|div}}
* <code><nowiki>{{Parameter|div|div}}</nowiki></code> generates: {{Parameter|div|div}}
