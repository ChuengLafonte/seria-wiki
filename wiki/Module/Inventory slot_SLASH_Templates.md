	--[[ OVERALL SYNTAX:
	[<key>] = {
		template = { ... },
		apply = { ... }
	}
	Each field consists of "template" and "apply". Note that "key" should be a unique key, and used for indexing purpose.
	
	"template" is the definition of a tooltip template. It is defined with the same syntax as a normal tooltip on Module:Inventory slot/Tooltips. A special syntax called "placeholder" can be used in any fields of the template. It is explained below:
		{s} and {o} can be used for insersion of (processed) new item id and (original) new item string respectively
		{r} and {l} can be used for insersion of the rarity color and the rarity long name respectively
			for example, for r='C' (common), {r} is '&f', and {l} is '&f&lCOMMON'
		{0}, {1}, {2}... can be used for custom variable placeholders (Uses zero indexing)
	
	"apply" is a list of items that uses the template. Each item will receive a copy of the template, and then amended with its own replacements and settings.
		Each item is defined as: { <New Item String or Table> ..., <global settings> }
		Using a string:
			Adding an item using a string will be equivalent as this in tooltips:
			[<New Item String>] = {
				name = <New Item String>,
				title = <title from template>,
				text = <text from template>
			}
			* optionally, you may use {s} on any position of title/text to insert the Tooltip String.
		Using a table:
			Besides using a string, a table can be used to **override template content** or **insert variables**.
			Override content: You can override any of the above with a table.
				Any "placeholder" syntax in "templates" may also be used here!
				For example, to replace the title: { <New Item String>, title = <Custom title> }
			Insert variables: You can insert variables with subsequent table elements.
				For example, to indicate values for {0} and {1}: { <New Item String>, 'Green', '&a' }
		Global Settings: available global settings can be applied as extra fields in the table, e.g. { ..., r = "E" }
			id: Override item id/key on ALL table values (refered as {o}, the original string).
				Note: the new id/key after replacement will be refered as {s}, the new item id
			rarity/r: sets the rarity of the item to determine values for {r} and {l}
	]]
