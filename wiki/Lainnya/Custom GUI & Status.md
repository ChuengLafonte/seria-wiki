

Kami membuat custom GUI dan Status yang bisa Kamu gunakan untuk memaksimalkan pengalaman bermain kamu di Server Project Seria.

Kami sangat berharap kamu menikmati Custom GUI dan Status yang Kami buat ini![[File:GUI Banner 400x9001.png|center]]
=== I. Scoreboard Info ===
Saat ini Kamu bisa melihat beberapa status secara langsung di layarmu:[[File:GUI Scoreboard.png|center|320x320px]]
# '''Waktu :''' Menampilkan waktu server, jam dan tanggal.
# '''Musim, Hari :''' Menampilkan musim dan hari server. Serta hitung mundur pergantian musim.
# '''Koordinat :''' Menampilkan koordinat Kamu berada.
# '''Area :''' Menampilkan [[Sevis|kota]] / [[West Morakhi Castle|dungeon]] / biome yang ada di server.
# '''Power :'''  Menampilkan total [[Power]] karaktermu.
# '''Gins :''' Menampilkan jumlah [[Mata Uang|uang]] yang kamu miliki.
# '''IP :''' Menampilkan IP Server Project Seria.
